## Script Oficial de Auditoria e Download

O script [`baixar_e_validar_editais.py`](file:///home/Hugo/Documentos/iniciando/editais/baixar_e_validar_editais.py) permite reexecutar a qualquer momento a verificação de integridade e download:

```bash
# Auditar e validar todos os editais locais (SHA256, páginas, camadas de texto)
python3 file:///home/Hugo/Documentos/iniciando/editais/baixar_e_validar_editais.py

# Baixar apenas arquivos eventualmente ausentes
python3 file:///home/Hugo/Documentos/iniciando/editais/baixar_e_validar_editais.py --download-missing

# Forçar re-download completo de todas as fontes oficiais
python3 file:///home/Hugo/Documentos/iniciando/editais/baixar_e_validar_editais.py --force-redownload
```
